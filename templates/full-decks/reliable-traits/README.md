# 必备特质：靠谱（可靠能力 + 言行一致 + 在线状态）

基于 SainStore 模板（`.tpl-sainstore` 作用域）改写的 9 页内容 deck。  
原文：「靠谱 = 可靠能力 + 言行一致 + 在线状态」。

## 页面结构（9 页）

1. **Cover** — 三色圆环 + 主标题「必备特质：靠谱」
2. **Agenda** — 6 卡片议程
3. **Definition** — 什么是靠谱：给人确定性（VUCA / 常量 / 放心）
4. **Formula** — 公式三色 Pipeline（可靠能力 / 言行一致 / 在线状态）
5. **Capability** — 特质一：拥有成长型思维，持续精进
6. **Integrity** — 特质二：行胜于言，承诺必兑现
7. **Availability** — 特质三：在线状态（含正反两个真实案例）
8. **Self-Check** — 5 个自我提问
9. **Thanks** — 致谢页

## 用法

```bash
open templates/full-decks/reliable-traits/index.html
```
